# AGENTS.md - Storybook

Storybook development environment for Arizona Digital tokens and web components.

## Development

Start Storybook from the repository root:

```bash
npm run dev:storybook
```

When running, Storybook MCP is available at `http://localhost:6006/mcp`.

## Required MCP workflow

1. Use Storybook MCP to discover existing stories before creating or renaming one.
2. Generate MCP previews for every story changed or added.
3. Use the returned preview URLs as the canonical visual validation targets.
4. Include all returned preview URLs in the final report.

If MCP preview generation fails, report the failure and ask before using browser automation as a fallback.

## Story conventions

- Use Component Story Format with `Meta` and `StoryObj` types from `@storybook/html-vite`.
- Keep story rendering deterministic and escape dynamic values before inserting them into HTML.
- Confirm token names in `packages/tokens/tokens.json`; never guess paths or CSS custom properties.
- Keep reusable token parsing and grouping logic in `src/` with focused Vitest coverage.
- Do not edit `storybook-static/`; it is generated by the Storybook build.

## Validation

Run from the repository root:

```bash
npm run lint:storybook
npm run test:storybook
npm run build:storybook
```
