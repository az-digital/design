# Background Patterns

Background patterns are quiet accents behind a section's content. They never cover the section, and
text over them stays readable. Each pattern has its own tokens
(`az.component.background-pattern.<pattern>.*`): its image, and where and how big it's drawn. Every
pattern shares the same colors.

## Monsoon Rain

Short vertical lines, like falling rain, running down one edge of a section
(`background-pattern.monsoon.*`).

The pattern sits in a band along the section's **start** edge or its **end** edge (left and right
in left-to-right languages). The band is 20% of the section's width, but never narrower than 75px
or wider than 200px, so it stays a small accent at every screen size. The image is 300px square and
repeats down the band from the top.

## Color

A pattern takes its color from the surface it's on, through that surface's on-color group:

- **Default surface** (White): <Token data={getTokenData('az.color.semantic.on-default.pattern')} /> (Rain),
  with dark text.
- **Brand surface** (Blue): <Token data={getTokenData('az.color.semantic.on-brand.pattern')} /> (Rain),
  with White text.

For Monsoon Rain, these two combinations passed an accessibility review: White text on Blue keeps
about 6.0:1 contrast where the pattern is darkest behind it, and dark text on White about 16.8:1.
Test any other section color, or a new pattern, before using it.

## Images

A pattern's image token, such as <Token data={getTokenData('az.component.background-pattern.monsoon.image')} />,
is the pattern itself: the build embeds its SVG in the token's output, so it works wherever the
tokens do, with no files to host. The SVG is a mask, not a picture: it holds the pattern's shape and
its opacity (40% for Monsoon Rain), and the surface's pattern color paints it. One image works on
every surface, and the color can change without a new file. The source SVGs ship with the tokens
package in `assets/patterns/`.

## Adding a pattern

1. Add its SVG to `assets/patterns/` as a mask: black shapes, with its opacity built in.
2. Add a group for it, `background-pattern.<pattern>.*`, with an `image` token pointing at the file
   and the tokens for where and how big it's drawn. Name it after the pattern, without color names.
3. Add an example to this page, on each surface it's approved for.
