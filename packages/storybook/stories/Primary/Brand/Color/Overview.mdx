# Color

Arizona's brand palette provides the visual foundation for the design system. Interface colors use the tokens for what they color and where, such as `az.color.bg.*` and `az.color.fg.*`, which point at these brand colors.

The swatches below document the brand palette. They don't replace choosing the token for a particular use in an interface, or checking its contrast.
