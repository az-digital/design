# Button

An action in a form, a dialog or a page: a label, and an optional icon, in a fully rounded
shape.

- **Keyboard focus:** a focused button looks the way it does on hover, with a ring 2px
  outside it. Its width is the shared <Token data={getTokenData('az.focus-ring.width.md')} />.
  The ring is <Token data={getTokenData('az.color.brand.bougainvillea')} /> on the Red
  buttons, White on outline Rain and the White buttons, and the button's own color on the
  others.
- **Colors that aren't brand colors,** such as Rain's hover fill, are recorded with a note
  saying why.

## Size

- **Default:** 46px tall: 18px text on a 24px line, with 9px of padding above and below
  and 28px to each side.
- **Small:** 29px tall: 16px text on a 19px line, with 3px above and below and 11px to
  each side.
- **Large:** 55px tall: 22px text on a 27px line, with 12px above and below and 34px to
  each side, and 0.18px letter spacing instead of 0.14px.

Every size has a 2px border, so outline and solid buttons line up, and fully rounded ends.
The label is Proxima Nova Condensed Bold. An icon sits 4px from the label and doesn't
change the button's height. Colors change over 150ms, ease-in-out, which hasn't been
reviewed by design yet and turns off when someone asks for reduced motion.
