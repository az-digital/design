# Call to Action Card

A title, text and one button, for one action. The whole card is clickable: the button's
link covers it, so pressing anywhere on the card does what the button does.

<Canvas of={CallToActionCardStories.Default} sourceState="hidden" />

<Controls of={CallToActionCardStories.Default} />

The card above is Arizona Bootstrap v5.3.0.

The button has Arizona Bootstrap's `.stretched-link` class, which stretches its link over the whole card. Arizona Bootstrap gives a Cloud card its title and text colors only with `.hover`, which this card doesn't use, so it sets them with `.text-azurite` on its title and `.text-tinta` on its text, and `.mt-3` puts the button 32px below the text.

## When to use it

- **Use it** for one thing to do, such as subscribing to a newsletter or registering for
  an event.
- **Write the button as the action,** in a word or two: "Subscribe", "Register".
- **One button per card.** For several links, use a
  <a href="./?path=/docs/primary-components-containers-cards-quick-links-card--docs" target="_top">Quick Links Card</a>.

## Design decisions

- **Button:** a default size Red
  <a href="./?path=/docs/primary-components-buttons-button--docs" target="_top">Button</a>,
  32px below the text.
- **The whole card is clickable:** the button's link covers the card, so a click or tap
  anywhere on it does what the button does. The button is the card's only link, and keyboard
  focus lands on it.
- **Fill:** <Token data={getTokenData('az.color.bg.card.cloud')} />, with no border. In a
  forced colors (high contrast) mode, which removes fills, the card draws a 1px border
  instead.
- **Title:** 22px Bold, on a 30px line, in
  <Token data={getTokenData('az.color.brand.azurite')} />. 8px below the title's line.
- **Text:** 18px Regular, on a 28px line, in
  <Token data={getTokenData('az.color.brand.tinta')} />.
- **Shape and padding:** 16px corners, and 24px between the card's edges and its content.
- **No hover colors on the card:** the card keeps its fill. The button reacts to hover
  anywhere on the card, and to keyboard focus.
