# Cards

A card holds one piece of content in a Cloud box. Pick a card by what the content is for:
whether the whole card goes to one page, and what goes with the title and text.

Every card has the same corners and title type, and every card but the Title on Image
Card has the same Cloud fill, padding and text type, so cards of different kinds sit
together in a row. Each card has its own contract in `packages/contracts`, and
its page shows that contract's anatomy.

On each card's page, the controls table is the card's props: what an editor fills in each
time, such as its title, its text and the page it goes to, with the required ones marked.
The contract holds the design decisions that are the same on every card, so a prop never
changes a color or a size.
