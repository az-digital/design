# Quick Links Card

A title, text and a list of related links. The card isn't a link itself: each link is
its own.

<Canvas of={QuickLinksCardStories.Default} sourceState="none" />

<Controls of={QuickLinksCardStories.Default} />

The card above is Arizona Bootstrap's 5.3.x branch. Edit Links to change the list.

Arizona Bootstrap has no styles for a card that isn't a link yet, so until its updates land the card above doesn't match every value on this page: its title is Blue, not Azurite, and its text is gray, not Tinta. Its links are Red, Regular and Proxima Nova, not Azurite, Semibold and Proxima Nova Condensed.

## When to use it

- **Use it** for a few links that belong together, such as the offices a student needs
  for one task.
- **Keep the list short:** three to five links. For more, link to a page that lists them.
- **Write each link as where it goes,** such as "Registrar & Transcripts", not "Click
  here".
- **If the card should go to one page,** use a
  <a href="./?path=/docs/primary-components-containers-cards-link-card--docs" target="_top">Link Card</a>
  instead.

## Design decisions

- **Links:** 18px Semibold, on a 28px line, in
  <Token data={getTokenData('az.color.brand.azurite')} />, underlined, in Proxima Nova
  Condensed. One per line, 12px apart.
- **Fill:** <Token data={getTokenData('az.color.bg.card.cloud')} />, with no border. In a
  forced colors (high contrast) mode, which removes fills, the card draws a 1px border
  instead.
- **Title:** 22px Bold, on a 30px line, in
  <Token data={getTokenData('az.color.brand.azurite')} />. 8px below the title's line.
- **Text:** 18px Regular, on a 28px line, in
  <Token data={getTokenData('az.color.brand.tinta')} />. 16px below the text, before the
  links.
- **Shape and padding:** 16px corners, and 24px between the card's edges and its content.
- **No hover colors:** the card isn't a link, so only each link reacts to hover and focus.
