# Select

A dropdown to pick one option from a list. It looks like a <a href="./?path=/docs/primary-components-inputs-text-input--docs" target="_top">text input</a>, with an arrow at its right end, and its labels and help text work the same way.

<Canvas of={SelectStories.Default} sourceState="none" />

<Controls of={SelectStories.Default} />

The select above is the current release. It matches this page. Valid and invalid states aren't recorded yet: their colors need marketing's approval.

## Colors

- **Text:** <Token data={getTokenData('az.color.brand.gray.900')} />, on <Token data={getTokenData('az.color.brand.white')} />, with a <Token data={getTokenData('az.color.brand.gray.600')} /> border.
- **Keyboard focus:** the border turns <Token data={getTokenData('az.color.brand.bougainvillea')} />, with a ring around it in the same color at <Token data={getTokenData('az.focus-ring.opacity')} /> (70%) opacity, <Token data={getTokenData('az.focus-ring.width.lg')} /> (4px) wide. It fades in over 150ms, ease-in-out, which hasn't been reviewed by design yet and turns off when someone asks for reduced motion.
- **Disabled:** the select fills <Token data={getTokenData('az.color.brand.gray.200')} />, with a <Token data={getTokenData('az.color.brand.gray.400')} /> border.
- **Arrow:** <Token data={getTokenData('az.color.brand.gray.800')} />, 16 × 12px, <Token data={getTokenData('az.spacing.150')} /> (12px) from the right edge.

## Size

- **Padding:** <Token data={getTokenData('az.spacing.075')} /> (6px) above and below the text, and <Token data={getTokenData('az.spacing.150')} /> (12px) to each side (36px on the right, to leave room for the arrow).
- **Type:** <Token data={getTokenData('az.font-size.base')} /> (18px) <Token data={getTokenData('az.font-weight.normal')} /> (Regular) on a 28px line.
- **Border:** <Token data={getTokenData('az.border.width.sm')} /> (1px), with <Token data={getTokenData('az.radius.2')} /> (6px) corners.
