# Arizona Header

## Colors

- **Blue** (default): the current, recommended header color
  (az-digital/arizona-bootstrap#2299).
- **Red**: the original header color. It's being retired, so don't use it for new sites.

## Tokens

`az.component.arizona-header.*` records the header's design decisions. Each token's
description names where its value comes from.

- **Fill:** <Token data={getTokenData('az.component.arizona-header.container.color')} />,
  through the <Token data={getTokenData('az.color.semantic.surface.brand')} /> surface:
  Blue by default. The original red header isn't a separate set of tokens: a theme
  would point `surface.brand` at Red (keeping `on-brand.*` White). There are no themes
  yet, and the red header is only needed until it's retired.
- **Size:** the header is at least 50px tall, and exactly 50px below 992px.
- **Keyboard focus:** the logo and header buttons draw a 2px ring inside their edges,
  with 2px corners, in <Token data={getTokenData('az.color.semantic.on-brand.focus-ring')} /> (White).
- **Header buttons** (for adding search and menu toggles on mobile): text and icons in <Token data={getTokenData('az.color.semantic.on-brand.default')} />
  (White), at least 60px wide and as tall as the header.
- **Logo:** the wordmark is a White image file, so no token colors it.
- **Fixed on mobile:** when the header is pinned to the top of the screen below 992px,
  linked sections stop 58px below the top when scrolled to, so the header doesn't
  cover them.
