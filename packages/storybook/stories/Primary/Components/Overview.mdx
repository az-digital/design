# Components

The Components section is the reusable library of interface patterns that teams can apply consistently across Arizona Digital products.

## Included groups

- Buttons
- Containers

This section is intentionally staged as a foundation for the initial system and can expand as new patterns are approved.

Each component's Docs page lists its design tokens. To browse or search every component's tokens together, see <a href="./?path=/docs/primary-tokens-overview--docs" target="_top">Tokens</a>.
