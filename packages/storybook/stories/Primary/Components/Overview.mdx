# Components

The Components section is the reusable library of interface patterns that teams can apply consistently across Arizona Digital products.

## Included groups

- <a href="./?path=/docs/primary-components-buttons--docs" target="_top">Buttons</a>
- <a href="./?path=/docs/primary-components-containers--docs" target="_top">Containers</a>

This section is intentionally staged as a foundation for the initial system and can expand as new patterns are approved.

## Contracts

Each component's design decisions are recorded in a contract: which token each part uses, at rest and in each state, and the component's own sizes and timings. Its docs page shows the contract as Anatomy tables, such as the <a href="./?path=/docs/primary-components-buttons-button--docs" target="_top">Button</a> page.
