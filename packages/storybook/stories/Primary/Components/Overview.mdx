# Components

The Components section is the reusable library of interface patterns that teams can apply consistently across Arizona Digital products.

Arizona's products are built in many different ways, so each component can come in more than one library. All of them follow the same Figma designs and the same component contracts. Pick the library that fits your product to read how it works. Your choice also switches every component page and story to that library, the same as the **Library** menu in the toolbar.
