# Color

Arizona's brand palette provides the visual foundation for the design system. Use semantic tokens for interface decisions such as text, surfaces, borders, and actions; use brand colors to explain the university identity and the base palette.

The swatches below document the brand palette. They are not a substitute for choosing an accessible semantic color for a particular interface use.

<ColorSwatchGrid prefix="az.color.brand." />

## Semantic colors

Semantic colors (`az.color.semantic.*`) are named for their purpose, not their appearance. Each one points at a brand color, and components use them instead of brand colors directly, so changing one updates every component that uses it for that purpose. For example, <Token data={getTokenData('az.color.semantic.action.default')} /> is the resting color of a primary action. Open a token to see its alias tree, including which component tokens use it.
