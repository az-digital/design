# Color

Arizona's brand palette provides the visual foundation for the design system. Use semantic tokens for interface decisions such as text, surfaces, borders, and actions; use brand colors to explain the university identity and the base palette.

The swatches below document the brand palette and its print values. They are not a substitute for choosing an accessible semantic color for a particular interface use.
