# Grids and Spacing

## Spacing scale

Use the shared spacing scale instead of introducing one-off values. Smaller steps support compact gaps within components and related content; from 48px onward, the scale uses broader steps for page and section layout.

The jump from 24px to 48px is intentional: the scale moves from component-level spacing to larger layout separation rather than adding every intermediate value.

Choose the smallest step that gives the intended separation and keep similar relationships consistent. Use `min` only for a one-pixel optical adjustment or a nearly flush edge, not as a routine gap. Use `card` for the inset between a card's edge and its content; its 20px value is contextual rather than another numbered step.

When a component contract describes ordinary spacing, reference the existing `az.spacing.*` step that matches the design. Use a contract-owned value only when the component genuinely needs a distinct value that the shared scale cannot express, and document why.

For how spacing tokens are named, see <a href="./?path=/docs/primary-foundations-tokens-naming--docs" target="_top">Naming</a>.
