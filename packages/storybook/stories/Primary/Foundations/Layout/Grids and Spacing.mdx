# Grids and Spacing

## Spacing scale

The bars use the current pixel values from the spacing tokens. Use the shared scale instead of introducing one-off spacing values.

<SpacingScale />

Choose a spacing token whose value matches the intended gap and use it consistently for similar relationships. In a component contract, reference a shared spacing token when it expresses the design; keep component-specific spacing in the contract and document why.

For how spacing tokens are named, see <a href="./?path=/docs/primary-foundations-tokens-naming--docs" target="_top">Naming</a>.
