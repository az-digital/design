# Grids and Spacing

## Grid and container

Pages use a 12-column grid inside a centered container. The gutter is 24px between columns (12px on each side of a column), the same as `az.spacing.4`. Containers have 12px of padding on each side, half the gutter; that padding is derived from the gutter, so it has no separate token.

The maximum container width changes at each breakpoint. Below `sm`, it stays fluid; from `sm` up, each breakpoint sets a maximum width.

The column count, gutter and container widths follow the current implementation (5.2.2). Figma's layout grids supply values the implementation doesn't set; no differing value is recorded for these decisions.
