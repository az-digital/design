# Layout Overview

Layout guidance describes how content is arranged and adapts to screen width, helping pages feel consistent across sites.

## How the pieces fit

- <a href="./?path=/docs/primary-foundations-layout-breakpoints--docs" target="_top">Breakpoints</a> are the widths where layouts change. Styles apply from a width up (mobile-first).
- <a href="./?path=/docs/primary-foundations-layout-grids-and-spacing--docs" target="_top">Grid and container</a> set the columns and the maximum width of the content.
- <a href="./?path=/docs/primary-foundations-layout-grids-and-spacing--docs#spacing-scale" target="_top">Spacing scale</a> sets the gaps between and inside content.

## Where decisions live

Breakpoints, grid, and spacing are shared tokens. A component's own layout, such as a card's padding, belongs in its contract.
