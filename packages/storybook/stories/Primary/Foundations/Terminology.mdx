# Design system terminology

This dictionary explains terms used in the Arizona Digital design system.

| Term | Definition |
| --- | --- |
| Component | A reusable part of a website, such as a button, card, or form field, that provides a specific function or content pattern. |
| Foundation | Shared design guidance and resources, such as accessibility, layout, and content guidance, that support the rest of the design system. |
| Primitive | A basic design value, such as a color or spacing amount, used to build more specific design choices. |
| Token | A named, reusable design value, such as a color, spacing amount, or font size, that helps keep designs consistent. |
