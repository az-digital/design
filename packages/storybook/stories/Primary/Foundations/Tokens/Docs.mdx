## Colors

Arizona's brand palette (`az.color.brand.*`), the raw color values every other color token is built from.

### Neutral colors

Colors outside the brand palette (`az.color.neutral.*`), for rules and dividers that shouldn't draw attention.

## Primitives

Named values that semantic and component tokens point at, where the name is a role rather than the value itself, so the value can change everywhere at once. Sizes, weights, durations and easings aren't primitives: each token holds its own, and tokens share a value only when it's the same decision. Use semantic or component tokens in designs and code, not primitives.

### Font families

Typefaces with their fallbacks (`az.font-family.*`).

## Semantic colors

Purpose-based aliases onto the brand palette (`az.color.semantic.*`), named for what a color is for, never for what it looks like. `surface.*` holds background colors that content sits on. `surface.brand` is the surface that follows the brand: Blue (Arizona's primary color 2) by default, and a theme can point it at another primary color. Each surface has an on-color group, such as `on-brand.*`, for the text, icons and focus rings that sit on it; a theme that repoints a surface repoints its on colors with it. Every value traces back to a brand or neutral color, so a design decision changes in one place. Use these, not brand colors, in components and production UI.

<TokenDisplay prefix="az.color.semantic." layout="table" />

## Semantic dimensions

Purpose-based sizes (`az.dimension.semantic.*`) that apply across a page rather than to one component. `page.scroll-offset` is how far below the top of the screen a linked section stops when the page scrolls to it; a fixed header raises it so it doesn't cover the section.

## Component tokens

Tokens scoped to a single component (`az.component.<component>.*`), so each component's design decisions are explicit and inspectable instead of implicit in its CSS. Structure shared by all of a component's variants sits at its root; each variant (a style like `solid` or `outline`, or a size) holds only what it changes. Colors point at semantic tokens; sizes, weights and timings are set on the component token itself.

Expand a component to see its tokens by group, or search across every component by name, type, alias, or value (e.g. `semantic.action.default` finds every component token built on it). Each component's Docs page and the **Tokens** tab on its stories show the same tokens in context.
