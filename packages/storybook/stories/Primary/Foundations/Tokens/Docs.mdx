## Colors

Arizona's brand palette (`az.color.brand.*`), the raw color values every other color token is built from.

<ColorSwatchGrid prefix="az.color.brand." />

## Primitives

Raw values, grouped by type of measurement, that component contracts point at. Each name is the value itself, such as `az.dimension.50` for 50px, so a primitive never changes meaning. To change a component's size or timing, point its contract at a different primitive; don't change the primitive's value.

### Dimensions

Sizes and spacing (`az.dimension.*`), in pixels, smallest first.

### Durations

How long a change takes (`az.duration.*`), in milliseconds.

### Easings

How a change speeds up and slows down (`az.easing.*`), as cubic Bézier curves.

## Shared decisions

Decisions every component that needs them shares, so they change in one place. Each is named the way implementations already name the same decision: `az.focus-ring.width` is the focus ring's width wherever one is drawn.

<TokenDisplay items={getTokenDisplayItems('az.focus-ring.', { order: 'source' })} layout="table" />

## Components

Components don't have tokens of their own. Each component's contract (`packages/contracts`) points each of its parts' design properties straight at a brand color, a primitive or a shared decision, and its docs page shows that wiring as an Anatomy table.
