# How to Use Design Tokens

Use Arizona Digital's design tokens in Figma by importing `tokens.json` as Figma Variables. You don't need repository access or a sync plugin to use them.

## Before you start

- A <a href="https://www.figma.com" target="_blank" rel="noreferrer">Figma</a> account (an <a href="https://www.figma.com/education/" target="_blank" rel="noreferrer">EDU account</a> works fine) with edit access to the file you're working in — the desktop app or the web app both work.

## Import into Figma Variables

1. <a href="#" onClick={(event) => { event.preventDefault(); downloadJson(tokensDocument, 'tokens.json'); }}>Download tokens.json</a>.
2. Open the **Variables** tab in your Figma file.
3. Select **Import** and choose the downloaded `tokens.json` file.
4. Apply semantic variables to design layers instead of entering hard-coded values.

> This import workflow is for using the tokens. Tokens Studio and GitHub access are only required when <a href="./?path=/docs/primary-foundations-tokens-contributing--docs" target="_top">contributing</a> changes back to the repository.

## Keeping tokens up to date

Re-downloading and re-importing `tokens.json` every time it changes is manual. If you'd rather keep Figma in sync automatically, install the <a href="https://www.figma.com/community/plugin/843461159747178978/tokens-studio-for-figma" target="_blank" rel="noreferrer">Tokens Studio for Figma</a> plugin and connect it to the repository as a <a href="https://docs.tokens.studio/token-storage/manage-sync-provider/" target="_blank" rel="noreferrer">sync provider</a> — then you can pull the latest tokens straight into Figma instead of downloading a new file each time. See <a href="./?path=/docs/primary-foundations-tokens-contributing--docs" target="_top">Contributing</a> for how to set that connection up.

## Applying tokens in your designs

- Use semantic tokens for production-facing text, surfaces, borders, and states.
- Use brand tokens (`az.color.brand.*`) for token creation and audits, not direct production UI assignments.
- Keep layers bound to variables so future imports can update values consistently.

Need to update the source tokens? Continue to <a href="./?path=/docs/primary-foundations-tokens-contributing--docs" target="_top">Contributing</a>.
