# Primary Design System

The Arizona Digital design system brings together university brand guidance, shared design foundations, reusable interface components, and the tokens that carry design decisions into tools and code.

## Explore the system

- [Brand](./?path=/docs/primary-brand-overview--docs): University identity and guidance for using the brand palette.
- [Foundations](./?path=/docs/primary-foundations-overview--docs): Shared principles and guidance for color, layout, typography, accessibility, content, interaction, and usability.
- [Tokens](./?path=/docs/primary-tokens-overview--docs): Design values organized by brand, semantic purpose, and component; learn how to use them in [Figma](./?path=/docs/primary-tokens-using-in-figma--docs) or [code](./?path=/docs/primary-tokens-using-in-code--docs), or [contribute](./?path=/docs/primary-tokens-contributing--docs).
- [Components](./?path=/docs/primary-components-overview--docs): Reusable interface patterns for consistent product experiences.

## Foundations

Foundations captures guidance shared across products and components:

- [Color](./?path=/docs/primary-foundations-color--docs)
- [Layout](./?path=/docs/primary-foundations-layout-overview--docs), including grids, spacing, and breakpoints
- [Typography](./?path=/docs/primary-foundations-typography--docs)
- [Accessibility](./?path=/docs/primary-foundations-accessibility--docs)
- [Content Design](./?path=/docs/primary-foundations-content-design--docs)
- Interaction: inputs, selections, and states
- [Usability](./?path=/docs/primary-foundations-usability-overview--docs)

Brand-color guidance lives with Foundations: Color. Tokens are a separate top-level section because they are a delivery layer for design decisions, not a Foundations topic.

## Components

Components organizes reusable interface patterns, including [Buttons](./?path=/story/primary-components-buttons--docs) and [Containers](./?path=/docs/primary-components-containers--docs).
