# Tokens

Tokens are the layer that carries design decisions into design tools and code. The source values are organized by tier:

- **Brand tokens** define the identity palette and other brand primitives.
- **Semantic tokens** give values meaning in context, such as text, surfaces, and actions.
- **Component tokens** tune a specific component or state.

Use semantic tokens first when making product-facing decisions. Refer to brand tokens when explaining the palette or how semantic values are derived; use component tokens for component-specific decisions.

Learn how to <a href="./?path=/docs/primary-tokens-using-in-figma--docs" target="_top">use tokens in Figma</a>, <a href="./?path=/docs/primary-tokens-using-in-code--docs" target="_top">use tokens in code</a>, or <a href="./?path=/docs/primary-tokens-contributing--docs" target="_top">contribute token changes</a>. For the brand palette and its usage guidance, see <a href="./?path=/docs/primary-foundations-color--docs" target="_top">Foundations: Color</a>.

## Semantic tokens

Colors named for their purpose, not their appearance (`az.color.semantic.*`). Each one points at a brand color, and components point at these instead of at brand colors directly, so changing one semantic token updates every component that uses it for that purpose. Open a token to see its alias tree, including which component tokens use it.

<TokenDisplay prefix="az.color.semantic." layout="table" />

## Component tokens

Tokens scoped to a single component (`az.component.<component>.*`), so each component's design decisions are explicit and inspectable instead of implicit in its CSS. Structure shared by all of a component's variants sits at its root; each variant (a style like `solid` or `outline`, or a size) holds only what it changes. Colors point at semantic tokens; sizes, weights, and opacities point at primitive values.

Expand a component to see its tokens by group, or search across every component by name, type, alias, or value (e.g. `semantic.action.default` finds every component token built on it). Each component's Docs page and the **Tokens** tab on its stories show the same tokens in context.
