# Tokens

Tokens are the layer that carries design decisions into design tools and code. They include:

- **Brand colors** (`az.color.brand.*`): the palette every other color is built from.
- **Colors for what they color and where**, such as `az.color.bg.button.red-hover` and `az.color.fg.white`, which point at brand colors.
- **Scales and shared decisions**, such as spacing, radius, type sizes and the focus ring's width.

Every token is named the way <a href="./?path=/docs/primary-tokens-naming--docs" target="_top">Naming</a> describes.

Components don't have tokens of their own. Each component's contract points its parts at these tokens and holds what's specific to it, such as its sizes and timings. Its docs page shows the contract as Anatomy tables.

Learn how to <a href="./?path=/docs/primary-tokens-using-in-figma--docs" target="_top">use tokens in Figma</a>, <a href="./?path=/docs/primary-tokens-using-in-code--docs" target="_top">use tokens in code</a>, or <a href="./?path=/docs/primary-tokens-contributing--docs" target="_top">contribute token changes</a>. For the brand palette and its usage guidance, see <a href="./?path=/docs/primary-brand-color--docs" target="_top">Brand: Color</a>.
