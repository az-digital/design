# Using in Figma

Start with Arizona Digital's UI Kit in Figma to build designs with shared components and styles, rather than importing design tokens into each file.

## Start with the UI Kit

<a href="https://www.figma.com/design/IzegZqsNTeUar61NGRfIjw/AZ-Digital-UX-Design-System?node-id=2017-20" target="_blank" rel="noreferrer">Open the Arizona Digital UI Kit in Figma (working copy)</a>.

This is the team's working copy, not a finalized release. Its contents may change as the design system develops.

1. Sign in to Figma and open the UI Kit. If you can't open it, request access through Figma.
2. Use the kit's available components and styles as the starting point for your designs.
3. Check the component's Storybook documentation for its anatomy, states and usage guidance.

You don't need repository access or a Tokens Studio sync connection just to use the UI Kit.

## Applying tokens in your designs

- Color text, surfaces, borders and states with the tokens for what they color and where (`az.color.bg.*`, `az.color.fg.*`).
- Use brand tokens (`az.color.brand.*`) to explain the palette, not in place of those tokens in production UI.
- Preserve component instances and their variable or style bindings where available instead of replacing them with hard-coded values.

## Advanced: working directly with tokens

Importing or syncing tokens is a separate workflow for people maintaining token bindings or contributing design-system changes, not a prerequisite for using the UI Kit. See <a href="./?path=/docs/primary-tokens-contributing--docs" target="_top">Contributing</a> for Tokens Studio setup, pulling repository updates, and exporting tokens to Figma variables.
