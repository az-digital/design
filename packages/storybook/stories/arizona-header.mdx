# Arizona Header

The University of Arizona wordmark header, required on all `arizona.edu` subdomains.
Confirmed **Arizona-custom** in the real docs ("Custom Arizona Bootstrap Component") —
unlike Accordion/Tabs/Nav/Card, there's no equivalent of this in upstream Bootstrap at
all. Purely presentational — no real interactive behavior in its base form, so this is
hand-rolled rather than wrapping `react-bootstrap`.

The logo link itself (`href`, `title`, `alt`, image `src`) is **fixed UA brand
content, not a prop** — every real, documented example uses the exact same ones, so
there's nothing to make configurable here.

## Variants

- **Blue** (default) — the current, recommended variant.
- **Red** (`variant="red"`) — the original header color. Still real and demonstrated
  in the docs, but marked there for future deprecation.
- **`fixedOnMobile`** — adds `.az-fixed-header-on-mobile`, pinning the header to the
  top of the viewport on narrow screens. **Only meaningful paired with off-canvas
  content** (a search/menu toggle revealing a panel below the header) — with nothing
  else in the header, it just hard-caps the header's own height on mobile for no
  benefit. Because of that, there's no dedicated story for it here: demonstrating the
  flag alone, without the off-canvas content it exists for, would model a combination
  the real docs never show and actively discourage.

## Not covered by this component (yet)

Arizona Bootstrap's own docs describe an **"Extending the header"** pattern: adding
off-canvas search and navigation toggles for mobile, using Bootstrap's real Offcanvas
plugin (`data-bs-toggle="offcanvas"`) and a `.btn-arizona-header` button style. That's
genuine interactive behavior this component doesn't cover yet — a future version
wrapping `react-bootstrap`'s `Offcanvas`, most likely, once there's a real need for it.

## Anatomy

The header's contract (`arizona-header.contract.json`) records the bar's height on small screens and the logo's spacing and size, below and from the `sm` breakpoint. Every value comes from Arizona Bootstrap's compiled CSS. Its blue and red fills come from Arizona Bootstrap's `bg-blue` and `bg-red` classes.
