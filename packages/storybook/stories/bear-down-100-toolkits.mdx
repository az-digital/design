# Toolkits and campaigns

This page defines the difference between university toolkits and campaigns and clarifies how those resources relate to the core design system.

## Key definitions

- Toolkit: outside the core design system but used to support university communications and product work
- Campaign: a structured effort within the design system or a defined campaign system with its own lifecycle
- Design system: the shared, reusable set of standards and patterns for digital work
